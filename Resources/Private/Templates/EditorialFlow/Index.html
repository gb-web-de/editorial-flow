No layout and no sections on purpose. The core DocHeader (breadcrumb, page-tree toggle, shortcut button) is configured in EditorialFlowController::indexAction() and rendered by ModuleTemplate around this template, so nothing here needs to reproduce it. See ARCHITECTURE.md and web-vision/kanban-workspaces#43. Note f:comment, not an HTML comment: Fluid parses ViewHelper tags inside HTML comments too, so writing a tag name there in angle brackets opens a real node that is never closed and breaks the template.
Select a page in the page tree to see its board.
Permission-gated: only rendered when the current backend user actually has access to more than one workspace (WorkspaceService::getAvailableWorkspaces() in EditorialFlowController::indexAction() is already filtered through core's own checkWorkspace()) - a single-workspace editor never sees a filter with nothing meaningful to filter. A checkbox multiselect, not a single-value select: several other workspaces' stages are now merged straight into the board's own stage columns (see BoardColumnRegistry), so narrowing "which other workspaces contribute cards" is no longer a single choice. Defaults to every workspace checked - board/filters.js reads these, never the server.
